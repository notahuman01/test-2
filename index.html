Best Charades vs Best ActivityNet Recipe: Mathematical Differences

Date: 2026-05-12

This note compares the current best confirmed Charades recipe with the current best confirmed ActivityNet recipe:

  • Charades: experiments/cycle12/46_charades_final_alpha06_maxend_confirm/01_candidate_alpha0.6_maxend0.35
  • ActivityNet: experiments/cycle14/19_activitynet_exact_compat_full_cand08_k12_gamma090_argmax050
The short version: Charades wins with a modern, regularized stack: hybrid token scoring, dynamic onset weighting, quality-degradation negatives, contrastive proposal scoring, and modern dynamic refinement. ActivityNet wins with a simpler exact-notebook-compatible path: hard token max, no negatives, no beta, exact v0 static proposal scoring, notebook start-shift compatibility, fewer final candidates, and a strong argmax proposal bonus.

Timeline Scoring

Let x_{n,p} be the video token feature at frame n and token p, and let q_m be text query feature m.

u_{m,n,p} = q_m dot x_{n,p}

Charades: Hybrid Token Score

Charades uses alpha=0.6, temp=0.03, so each frame gets a mixture of hard max and log-sum-exp token pooling:

h_{m,n} = max_p u_{m,n,p}
lse_{m,n} = tau * log(sum_p exp(u_{m,n,p} / tau))
s_{m,n}^{hybrid} = alpha * h_{m,n} + (1 - alpha) * lse_{m,n}

s_{m,n}^{Charades} = 0.6 * h_{m,n} + 0.4 * lse_{m,n},  tau = 0.03

Then Charades applies quality-negative suppression:

qneg_{n,k} = max_p (z_k dot x_{n,p})
w_{n,k} = softmax_k(qneg_{n,k} / tau_neg)
Q_n = sum_k w_{n,k} * qneg_{n,k}
s_n' = s_n - lambda_Q * Q_n

lambda_Q = 0.15
quality_neg_preset = cvd2014_tid2013
quality_neg_aggregation = softmax

Finally, Charades uses dynamic onset weighting with beta=0.25:

s_n'' = s_n' * (1 + beta * onset_n)

Charades: beta = 0.25
ActivityNet: beta = 0.0

ActivityNet: Exact Notebook Hard Max

ActivityNet has alpha=0.0 and temp=0.0, so the code bypasses hybrid token scoring:

s_{m,n}^{AN} = max_p u_{m,n,p}

There are no quality negatives and no dynamic onset weighting:

Q_n = 0
beta = 0
s_n^{AN-final} = s_n^{AN}

Proposal Scoring

For a candidate span [a,b), define:

L = b - a
I(a,b) = mean_{n in [a,b)} s_n
O(a,b) = mean_{n not in [a,b)} s_n

Charades: Generalized Contrastive Score

score_{base}(a,b) = I(a,b) - beta_c * max(O_raw(a,b), O_floor)

Here beta_c = contrastive_beta = 1.0, and O_floor is the global outer floor derived from low-scoring frames. Charades also rejects spans longer than half the video:

b - a <= prior * N = 0.5N

ActivityNet: Exact v0 Static Score

score_{v00}(a,b) = I(a,b) - O(a,b)

No outer floor is applied in this exact path. Then the winning ActivityNet run applies the argmax-containing proposal multiplier:

score_{AN}(a,b) =
  round(score_{v00}(a,b) * (1 + 0.5 * 1[argmax(s) in [a,b)]), 4)

The max-length prior is:

b - a <= 1.0N

Refinement

Charades: Modern Dynamic Refinement

enable_dynamic_refinement = true
dynamic_refinement_mode = both
dynamic_refinement_start_behavior = expand_only
dynamic_refinement_end_behavior = expand_only
dynamic_refinement_max_end_ratio = 0.35

Conceptually, for each proposal [a,b), the refinement step considers nearby boundary variants:

(a', b') in R(a,b)

ActivityNet: Notebook Start-Only Compatibility

enable_dynamic_refinement = false
v00_start_refinement_compat = true
v00_start_refinement_ths = 0.0005

Conceptually, only the proposal start is shifted left to the dynamic segment boundary:

a' = left_boundary(a),  b' = b

Voting

Both use voting_method: original. Given proposals p_i = [a_i,b_i] with nonnegative proposal weights w_i, the original voting score is:

V_i = sum_j IoU(p_i, p_j)^gamma_nms * max(w_j, 0)

gamma_nms = 0.6
prediction = argmax_i V_i

Important naming note: this nms_gamma=0.6 is the voting exponent. It is different from the top-level gamma used earlier in score alignment / Box-Cox-style processing:

Charades top-level gamma = 0.2
ActivityNet top-level gamma = 0.9
Both nms_gamma = 0.6

Practical Takeaway

Do not blindly port the Charades best stack to ActivityNet.

Charades Best

hybrid alpha/temp
+ beta onset
+ quality negatives
+ contrastive scoring
+ modern dynamic refinement
+ prior=0.5

ActivityNet Best

exact v00 hard max
+ normalized clustering
+ v00 static scoring
+ notebook start shift
+ cand_num=8
+ kmeans_k=12
+ gamma=0.9
+ argmax_bonus_alpha=0.5
+ no negatives
+ no modern refinement

The shared lesson is not "use the same modules." The shared lesson is that each dataset wants a different bias:

  • Charades wants precision shaping and boundary regularization.
  • ActivityNet wants exact notebook signal geometry plus a compact candidate set and strong argmax-centered proposal ranking.
