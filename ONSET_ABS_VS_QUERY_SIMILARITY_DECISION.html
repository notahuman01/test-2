Onset Abs vs Query-Similarity Pooling

Empirical comparison and mathematical interpretation for deciding whether query-similarity pooling should become universal or remain a Charades-specific enhancement on top of the onset_abs architecture.

Universal module

onset_gradient_mode: abs is stable: Charades improves and ActivityNet ties mIoU while slightly lifting strict recall.

Charades-only candidate

query_similarity_tau: 0.10 improves Charades from 48.45 to 48.77 mIoU.

ActivityNet transfer

The best completed ActivityNet query-similarity full row is 37.81, below the 37.91 onset_abs anchor.

Why Onset Abs Makes Sense

onset_abs rewards the magnitude of temporal semantic change rather than only positive confidence rise. That matters because a useful temporal boundary can be a start, an end, or a transition between two actions.

background -> action
action -> background
action A -> action B

Positive onset assumes the useful boundary evidence is mostly rising confidence. Absolute onset says that large semantic change is useful boundary evidence regardless of direction. That fits the refinement stage because refinement needs boundary cues for both sides of a proposal.

proposal score -> boundary-change weighting -> start/end refinement
DatasetEffectInterpretation
Charades48.45 mIoU, above the positive-onset 48.32 anchorShort, dense actions benefit from sharper boundary-change cues.
ActivityNet37.91 mIoU tie, with slightly better R@0.5/R@0.7Safe as a shared module; does not damage broad ActivityNet events.

Why Query Similarity Makes Sense

Box temporal pooling smooths local temporal scores uniformly. Query-similarity pooling smooths through nearby frames according to how relevant each frame remains to the query.

box pooling:
pooled_score_t = average(score_neighbors)

query-similarity pooling:
pooled_score_t = weighted_average(score_neighbors, weight = query_frame_similarity)

This is mathematically attractive because it prevents unrelated local frames from contributing equally to the smoothed score. It says: smooth along query-relevant temporal support, not blindly across the window.

Paper story:
Onset_abs is a universal boundary-change module.
Query-similarity pooling is a Charades-beneficial semantic smoothing variant,
but not a universal replacement for box temporal pooling because ActivityNet remains stronger with the box anchor.
