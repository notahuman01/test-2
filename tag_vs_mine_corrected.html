What actually drives the gains — corrected summary
The gains come from five active algorithmic changes plus hyperparameter tuning — not from token selection, query decomposition, or negative ranking, which are all off in this run.

1. Cohen's d scoring — replaces mean-contrast with a std-normalized effect size. Prevents high-score plateaus from dominating long proposals.
2. Dynamic onset weighting (beta=0.55) — upweights frames at activity onset using a positive-gradient signal with confidence-contrast gating. This is the only mechanism that modifies the similarity timeline before masking and clustering — making it structurally novel vs TAG.
3. DA-NMS — replaces single-gamma soft NMS with a distribution-aware voting that uses boundary consensus signals.
4. Bidirectional boundary refinement — TAG only refines the start; mine also corrects the end boundary.
5. Normalized clustering features — changes the geometry of the k-means space from magnitude-skewed to cosine-uniform.

The hyperparameter changes (k=12, window=13, stride=40) cannot be cleanly separated from the algorithmic ones without ablation runs — they may account for a non-trivial portion of the gain.
Publishability verdict — unchanged framing recommendation
With the token selection and query decomposition correctly identified as off, the publishable story becomes cleaner and more honest: the gains come from a small set of principled, individually motivated changes — not an opaque parameter sweep. This is actually better for a paper.

Strongest angle: "We identify that TAG's scoring is not std-normalized (problematic for variable-length proposals), its refinement is unidirectional, and its timeline is not onset-aware. We fix each in isolation and validate with a failure-mode audit framework." This framing lets the diagnostic infrastructure be the paper's methodological centerpiece, and the per-fix ablation is the results section.

The key open question: Are the gains from changes 1–5 each independently contributing, or do they interact? You need at least a 5-row ablation table to claim them as separate contributions.
